# Proposal

## Why

Модератор, подавая запрос, вынужден выбрать другого модератора и ждать его решения: проверка первого уровня уже сделана тем, кто подал. Лишний шаг задерживает запрос, не добавляя проверки.

## What Changes

- Запрос, поданный человеком с ролью модератора, сохраняется в статусе «Отмодерировано»: он сразу ждёт финансового директора, модератором записан сам автор.
- Автор с ролью модератора может выбрать модератором себя; автор без этой роли — по-прежнему нет.
- Если автор с ролью модератора выбрал другого модератора, запрос идёт обычным путём.
- Повторная подача после возврата отправляет такой запрос снова в «Отмодерировано».

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `expense-requests`: запрос модератора минует модерацию.

## Impact

- Сервер: создание и повторная подача запроса, выбор модератором себя. Схема базы не меняется.
- API: поле `moderator_id` при создании необязательно для автора с ролью модератора.
- Веб-интерфейс: форма нового запроса не спрашивает модератора у автора с ролью модератора.
- Новых зависимостей нет.
