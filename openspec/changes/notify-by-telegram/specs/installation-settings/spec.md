# Spec Delta

## ADDED Requirements

### Requirement: Уведомления и бот Telegram

Система SHALL брать из настроек установки, включены ли уведомления, и при включённых уведомлениях данные бота Telegram, публичный адрес сервиса, язык сообщений и способ обращения к Telegram: напрямую или через прокси установки. Значения по умолчанию у настройки уведомлений нет: установка явно включает или выключает их.

Бот принадлежит организации, и только она решает, отправлять ли сведения о запросах во внешний сервис и каким путём до него добираться.

#### Scenario: Уведомления выключены

- **WHEN** установка явно выключает уведомления
- **THEN** сервис запускается без данных бота и не обращается к Telegram

#### Scenario: Уведомления включены

- **WHEN** установка включает уведомления и задаёт данные бота и публичный адрес сервиса
- **THEN** сообщения отправляет этот бот, ссылки в сообщениях ведут на этот адрес

#### Scenario: Telegram доступен только через прокси

- **WHEN** установка указывает, что к Telegram нужно обращаться через прокси, и задаёт его адрес
- **THEN** сервис отправляет сообщения и получает обновления бота через этот прокси

#### Scenario: Настройка не задана

- **WHEN** сервис запускают без настройки уведомлений
- **THEN** сервис не запускается, в сообщении названа эта настройка

#### Scenario: Уведомления включены без бота

- **WHEN** установка включает уведомления и не задаёт данные бота
- **THEN** сервис не запускается, в сообщении названа недостающая настройка

#### Scenario: Прокси указан без адреса

- **WHEN** установка указывает обращение к Telegram через прокси и не задаёт его адрес
- **THEN** сервис не запускается, в сообщении названа настройка адреса прокси
