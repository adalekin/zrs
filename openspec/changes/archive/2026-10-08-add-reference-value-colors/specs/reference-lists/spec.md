# Spec Delta

## ADDED Requirements

### Requirement: Цвет значения

Система SHALL разрешать финансовому директору задать значению любого из трёх справочников один цвет из палитры сервиса, сменить его и снять. В палитре восемь цветов: красный, оранжевый, жёлтый, зелёный, бирюзовый, синий, фиолетовый, розовый.

Значения справочников заводит сама организация, поэтому отметить, какие из них должны бросаться в глаза, может только тот, кто ведёт справочник.

#### Scenario: Финансовый директор задаёт цвет

- **WHEN** финансовый директор задаёт приоритету красный цвет
- **THEN** справочник показывает этот приоритет с красным цветом

#### Scenario: Смена цвета

- **WHEN** финансовый директор меняет цвет формы оплаты с жёлтого на синий
- **THEN** у формы оплаты синий цвет

#### Scenario: Снятие цвета

- **WHEN** финансовый директор снимает цвет со значения
- **THEN** у значения нет цвета

#### Scenario: Цвет не из палитры

- **WHEN** финансовый директор задаёт значению цвет, которого нет в палитре
- **THEN** система отклоняет изменение, цвет значения остаётся прежним

#### Scenario: Переименование значения с цветом

- **WHEN** финансовый директор переименовывает значение, у которого задан цвет
- **THEN** цвет значения остаётся прежним

### Requirement: Цвет меняет только финансовый директор

Система SHALL NOT разрешать задавать, менять и снимать цвет значения никому, кроме финансового директора.

Цвет входит в ведение справочника, а справочники ведёт один человек: тот, кто отвечает за учёт расходов.

#### Scenario: Цвет меняет модератор

- **WHEN** модератор пытается задать цвет значению справочника
- **THEN** система отказывает в действии, цвет значения остаётся прежним

### Requirement: Новое значение без цвета

Система SHALL создавать значение справочника без цвета.

Цвет отмечает то, что должно бросаться в глаза. Если бы он появлялся сам, отметка ничего бы не значила.

#### Scenario: Финансовый директор добавляет значение

- **WHEN** финансовый директор добавляет вид операции
- **THEN** у нового вида операции нет цвета

### Requirement: Цвет значения в запросах

Система SHALL выделять вид операции, приоритет и форму оплаты запроса цветом, который задан значению сейчас, в трёх местах: в строке списка запросов, в карточке списка на узком экране и на странице запроса. Значение без цвета показано без цветового выделения.

Цвет нужен, чтобы находить запросы с нужным значением с одного взгляда, поэтому он стоит там, где запросы читают, а не там, где их заполняют.

#### Scenario: Значение с цветом в списке

- **WHEN** человек открывает список, где есть запрос, приоритету которого задан красный цвет
- **THEN** в строке этого запроса приоритет выделен красным

#### Scenario: Значение с цветом в карточке на узком экране

- **WHEN** человек открывает тот же список на экране уже 640 px
- **THEN** в карточке этого запроса приоритет выделен красным

#### Scenario: Значение с цветом на странице запроса

- **WHEN** человек открывает запрос, приоритету которого задан красный цвет
- **THEN** приоритет выделен красным

#### Scenario: Значение без цвета

- **WHEN** человек открывает запрос, приоритету которого цвет не задан
- **THEN** приоритет показан без цветового выделения

#### Scenario: Цвет задан после подачи запроса

- **WHEN** финансовый директор задаёт цвет виду операции, который уже указан в поданных запросах
- **THEN** эти запросы показывают вид операции в новом цвете

#### Scenario: Выключенное значение с цветом

- **WHEN** человек открывает запрос, в котором указано выключенное позже значение с цветом
- **THEN** значение выделено своим цветом, как до выключения

### Requirement: Название значения рядом с цветом

Система SHALL показывать название значения справочника текстом везде, где значение выделено цветом, и название цвета текстом везде, где цвет выбирают.

Цвета различают не все люди и не все экраны: человек должен прочитать то, что другой узнаёт по цвету.

#### Scenario: Значение с цветом в запросе

- **WHEN** человек открывает запрос, приоритету которого задан красный цвет
- **THEN** рядом с цветом читается название приоритета

#### Scenario: Выбор цвета

- **WHEN** финансовый директор открывает выбор цвета значения
- **THEN** у каждого цвета палитры и у варианта «без цвета» подписано название
