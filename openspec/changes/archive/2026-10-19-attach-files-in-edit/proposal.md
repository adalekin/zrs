# Proposal

## Why

Документы на оплату меняются на странице просмотра запроса, а остальные поля в форме правки. Запрос возвращают автору чаще всего за недостающим счётом, автор идёт исправлять его в форму правки и не находит там, куда приложить файл.

## What Changes

- Форма правки запроса показывает документы на оплату: приложенные файлы с возможностью удалить и место, куда добавить новые.
- Изменения документов в форме применяются по кнопке «Сохранить» вместе с полями; отмена правки оставляет документы прежними.
- Страница просмотра запроса показывает документы только для скачивания: добавить или удалить файл на ней нельзя.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `expense-requests`: документы на оплату меняются только в форме нового запроса и в форме правки.

## Impact

- Веб-интерфейс: форма правки и страница запроса.
- Сервер, API и схема базы не меняются.
- Новых зависимостей нет.
