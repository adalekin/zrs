## MODIFIED Requirements

### Requirement: Документы на оплату

Система SHALL разрешать автору добавлять файлы к запросу и удалять их, пока запрос можно править, и SHALL отдавать файл каждому, кто видит запрос. Файл больше предела, заданного установкой, система SHALL отклонять. Добавить и удалить файлы автор может только в форме нового запроса и в форме правки; страница просмотра запроса показывает файлы для скачивания.

Счёт или договор должны лежать рядом с запросом, по которому платят. Документы входят в содержание запроса, поэтому меняются там же, где остальные поля: возвращённый запрос автор исправляет в форме правки.

#### Scenario: Автор прикладывает файл

- **WHEN** автор добавляет файл к запросу в статусе «Новая»
- **THEN** файл появляется в запросе, его может скачать модератор запроса

#### Scenario: Файл больше предела

- **WHEN** автор добавляет файл больше предела установки
- **THEN** система отклоняет файл и называет предел

#### Scenario: Файл к одобренному запросу

- **WHEN** автор добавляет или удаляет файл у запроса в статусе «Одобрено»
- **THEN** система отклоняет действие, набор файлов не меняется

#### Scenario: Файл чужого запроса

- **WHEN** человек запрашивает файл запроса, который он видеть не может
- **THEN** ответ не отличается от ответа на несуществующий файл

#### Scenario: Автор прикладывает счёт в форме правки

- **WHEN** автор открывает правку возвращённого запроса, выбирает файл счёта и сохраняет правку
- **THEN** файл появляется в документах запроса

#### Scenario: Документы видны в форме правки

- **WHEN** автор открывает правку запроса, к которому уже приложены файлы
- **THEN** в форме перечислены приложенные файлы, каждый можно удалить

#### Scenario: Автор удаляет файл в форме правки

- **WHEN** автор удаляет приложенный файл в форме правки и сохраняет правку
- **THEN** файла больше нет в документах запроса

#### Scenario: Отмена правки не меняет документы

- **WHEN** автор выбирает новый файл и удаляет приложенный в форме правки, а затем закрывает форму без сохранения
- **THEN** документы запроса остаются прежними

#### Scenario: Правка только документов

- **WHEN** автор в форме правки только добавляет файл, не меняя полей, и сохраняет правку
- **THEN** файл появляется в документах запроса, поля запроса не меняются

#### Scenario: Страница просмотра не меняет документы

- **WHEN** автор открывает страницу своего запроса в статусе «Ошибка»
- **THEN** приложенные файлы можно скачать, а добавить или удалить файл на странице нельзя

#### Scenario: Файл в форме правки больше предела

- **WHEN** автор выбирает в форме правки файл больше предела установки
- **THEN** форма не принимает файл и называет предел
