# Proposal

## Why

Этап запроса показан маленькой плашкой статуса: чтобы понять, на каком шаге каждый запрос списка, плашки приходится читать по одной.

## What Changes

- Строка списка запросов, карточка списка на узком экране и колонка доски залиты цветом этапа запроса; плашка статуса того же цвета.
- Отказ финансового директора и остальные отказы показаны разными цветами.
- У оплаченного запроса под статусом показана дата оплаты.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `expense-requests`: этап запроса показан цветом.

## Impact

- Веб-интерфейс: список, карточки списка, доска, плашка статуса, страница запроса, метки справочников, обе локали, снимки в README. Сервер и API не меняются.
- Изменение применяется после `show-who-rejected`: цвет отказа зависит от того, кто отклонил запрос.
- Новых зависимостей нет.
