# Spec Delta

## MODIFIED Requirements

### Requirement: Цвет значения в запросах

Система SHALL выделять вид операции, приоритет и форму оплаты запроса цветом, который задан значению сейчас, в четырёх местах: в строке списка запросов, в карточке списка на узком экране, на карточке доски и на странице запроса. Значение без цвета показано без цветового выделения.

Цвет нужен, чтобы находить запросы с нужным значением с одного взгляда, поэтому он стоит там, где запросы читают, а не там, где их заполняют.

#### Scenario: Значение с цветом в списке

- **WHEN** человек открывает список, где есть запрос, приоритету которого задан красный цвет
- **THEN** в строке этого запроса приоритет выделен красным

#### Scenario: Значение с цветом в карточке на узком экране

- **WHEN** человек открывает тот же список на экране уже 640 px
- **THEN** в карточке этого запроса приоритет выделен красным

#### Scenario: Значение с цветом на карточке доски

- **WHEN** человек открывает доску, где есть запрос, приоритету которого задан красный цвет
- **THEN** на карточке этого запроса приоритет выделен красным

#### Scenario: Значение с цветом на странице запроса

- **WHEN** человек открывает запрос, приоритету которого задан красный цвет
- **THEN** приоритет выделен красным

#### Scenario: Значение без цвета

- **WHEN** человек открывает запрос, приоритету которого цвет не задан
- **THEN** приоритет показан без цветового выделения

#### Scenario: Цвет задан после подачи запроса

- **WHEN** финансовый директор задаёт цвет виду операции, который уже указан в поданных запросах
- **THEN** эти запросы показывают вид операции в новом цвете

#### Scenario: Выключенное значение с цветом

- **WHEN** человек открывает запрос, в котором указано выключенное позже значение с цветом
- **THEN** значение выделено своим цветом, как до выключения
