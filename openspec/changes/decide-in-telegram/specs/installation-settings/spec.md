# Spec Delta

## ADDED Requirements

### Requirement: Решения из Telegram

Система SHALL брать из настроек установки с включёнными уведомлениями, разрешены ли решения из Telegram. Значения по умолчанию у этой настройки нет.

Решение из Telegram принимается без входа через провайдера организации, и допустимо ли это, решает организация.

#### Scenario: Решения разрешены

- **WHEN** установка включает уведомления и разрешает решения из Telegram
- **THEN** сообщения согласующим несут кнопки решений

#### Scenario: Решения запрещены

- **WHEN** установка включает уведомления и запрещает решения из Telegram
- **THEN** сообщения согласующим несут только ссылку на запрос

#### Scenario: Настройка не задана

- **WHEN** сервис запускают с включёнными уведомлениями и без настройки решений из Telegram
- **THEN** сервис не запускается, в сообщении названа эта настройка
